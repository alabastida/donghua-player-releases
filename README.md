# Donghua Player downloads

Public distribution repository for Donghua Player installers and signed update manifests. Application source code is maintained separately.

Download published installers from [Releases](https://github.com/alabastida/donghua-player-releases/releases). The first version with in-app updates requires a manual installation; subsequent updates will be offered inside the app.

Windows x64, macOS Apple Silicon, and Linux x64 are the planned targets. Installers are not OS-code-signed/notarized.
